codex-relay 安裝指南

    一步一步安裝 codex-relay

    codex-relay 讓每個 Claude Code 視窗各自選擇走 Claude 或 OpenAI Codex. 安裝分成兩部分: Rust 寫的 claude-code-proxy, 以及 Claude Code plugin.

    請依照順序執行每個步驟. 每個指令都有自己的「複製」按鈕, 一次只複製一行. 請先在右上角選擇你的作業系統.

    Claude Code ── ANTHROPIC_BASE_URL ──▶ relay (Node, 127.0.0.1:8960)
                                        ├─ session = claude ─▶ api.anthropic.com
                                        └─ session = codex  ─▶ claude-code-proxy (Rust, 127.0.0.1:8970)
                                                                 └─▶ chatgpt.com/backend-api/codex
    01

    檢查現有工具

    先確認電腦上已經有哪些工具. 開啟終端機, 逐行執行下面的指令.

    Windows 請使用 PowerShell 或 Windows Terminal.

    $node --version

    顯示 Node.js 的版本. 需要 v20 以上. Relay 和 plugin 都用 Node 執行.

    $git --version

    確認 Git 已經安裝. 步驟 05 用 Git 下載原始碼.

    $claude --version

    顯示 Claude Code 的版本. 需要支援 plugin hooks module 的版本 (已在 2.1.306 測試).

    $cargo --version

    確認 Rust toolchain 已經安裝. 步驟 05 用 cargo 編譯 proxy.

    任何一行顯示「找不到指令」或版本太舊, 請在後面的步驟安裝它. 全部都已經就緒時, 可以直接跳到 步驟 04.

    02

    安裝 Node.js, Git 與 Claude Code

    只安裝步驟 01 中缺少的工具. 已經有的工具請略過.

    Windows
    PS>winget install OpenJS.NodeJS.LTS

    用 Windows 內建的 winget 安裝 Node.js LTS 版本. 也會一併安裝 npm.

    PS>winget install Git.Git

    安裝 Git for Windows.

    PS>irm https://claude.ai/install.ps1 | iex

    下載並執行 Claude Code 的官方安裝程式. irm 下載腳本, iex 執行它.

    macOS
    $brew install node

    用 Homebrew 安裝 Node.js 與 npm. 沒有 Homebrew 時, 請先依照 brew.sh 安裝.

    $brew install git

    安裝 Git.

    Linux (Debian / Ubuntu)
    $sudo apt update

    更新 apt 的套件清單.

    $sudo apt install -y git

    安裝 Git. -y 自動回答「是」.

    發行版內建的 Node.js 版本常常低於 v20. 請到 nodejs.org/en/download 選擇 Linux, 依照頁面上的指令安裝 v20 以上的版本.

    $curl -fsSL https://claude.ai/install.sh | bash

    下載並執行 Claude Code 的官方安裝程式.

    $claude update

    Claude Code 已經安裝但版本太舊時, 用這行更新到最新版.

    安裝完成後, 關閉並重新開啟終端機. 新的終端機才會讀到更新後的 PATH. 然後重新執行步驟 01 的指令確認.

    03

    安裝 Rust toolchain

    Proxy 用 Rust 撰寫. 你需要 cargo 從原始碼編譯它. Rust 也需要系統的 C linker.

    Windows
    PS>winget install Microsoft.VisualStudio.2022.BuildTools --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"

    安裝 Visual Studio Build Tools 的 C++ 工作負載. Rust 在 Windows 使用 MSVC 的 linker. --override 後面的參數只選擇 C++ build tools. 已經安裝 Visual Studio C++ 開發工具時, 請略過這行.

    PS>winget install Rustlang.Rustup

    安裝 rustup. rustup 管理 Rust 的版本, 並安裝 rustc 和 cargo.

    關閉並重新開啟 PowerShell, 讓 PATH 包含 %USERPROFILE%\.cargo\bin.

    macOS
    $xcode-select --install

    安裝 Apple Command Line Tools, 內含 C compiler 和 linker. 如果顯示「already installed」, 代表已經安裝, 可以繼續.

    Linux (Debian / Ubuntu)
    $sudo apt install -y build-essential curl

    安裝 C compiler, linker 和 curl. 其他發行版請安裝對應的套件, 例如 Fedora 的 gcc.

    $curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

    下載並執行 rustup 的官方安裝腳本. 出現選單時, 按 Enter 選擇預設安裝.

    $. "$HOME/.cargo/env"

    把 ~/.cargo/bin 加進目前終端機的 PATH. 新開的終端機會自動載入, 不需要再執行.

    $cargo --version

    確認 cargo 可以執行. 看到版本號碼代表 Rust 已經就緒.

    04

    安裝 Codex CLI 並登入 ChatGPT

    Proxy 預設使用 Codex CLI 的 ChatGPT 登入. 你需要一個有 Codex 使用權的 ChatGPT 帳號.

    $npm install -g @openai/codex

    用 npm 全域安裝 OpenAI 的 Codex CLI. 安裝後可以在任何目錄執行 codex.

    $codex login

    開啟瀏覽器, 用 ChatGPT 帳號登入. 登入憑證會存在 ~/.codex/auth.json. Proxy 會讀取這個檔案, 不需要另外登入.

    05

    下載原始碼並安裝 proxy

    這個步驟從原始碼編譯 claude-code-proxy, 並把它放進 PATH.

    $git clone https://github.com/seanmars/codex-relay.git

    把 codex-relay 的原始碼下載到目前目錄下的 codex-relay 資料夾.

    $cd codex-relay

    進入剛剛下載的資料夾. 後面的指令要在這裡執行.

    $cargo install --path proxy

    編譯 proxy/ 資料夾裡的 Rust 專案, 並把執行檔安裝到 ~/.cargo/bin. 第一次編譯需要幾分鐘. 如果已經安裝上游的 claude-code-proxy, 這行會取代它.

    $claude-code-proxy --version

    確認 proxy 已經安裝, 而且在 PATH 裡.

    claude-code-proxy 0.1.45
    $claude-code-proxy codex auth status

    確認 proxy 讀得到步驟 04 的 Codex 登入. 顯示「Not authenticated」時, 請重新執行 codex login.

    $claude-code-proxy codex usage

    顯示 ChatGPT 方案的 Codex 用量上限. 能顯示用量, 代表登入憑證有效.

    你不需要手動啟動 proxy. Relay 在需要 Codex 時會自動啟動它.

    06

    安裝 Claude Code plugin

    Plugin 提供 /relay 指令, 面板, statusline 和 codex-relay:codex subagent. 它在 session 開始時自動啟動 relay.

    $claude plugin marketplace add seanmars/codex-relay

    把 GitHub 上的 seanmars/codex-relay 加入 Claude Code 的 marketplace 清單. Claude Code 從這個 repo 讀取 plugin.

    $claude plugin install codex-relay@codex-relay

    安裝 plugin. 格式是 plugin 名稱@marketplace 名稱, 這裡兩者都是 codex-relay.

    $claude plugin list

    列出已安裝的 plugin. 確認清單中有 codex-relay, 而且狀態是 enabled.

    Plugin 只對目前的 session 設定 ANTHROPIC_BASE_URL. 它不會修改 settings.json. Relay 沒有回應時, session 會使用原本的位址.

    07

    開啟 Claude Code 並驗證

    下面第一行在終端機執行. 其他以 / 開頭的指令, 請在 Claude Code 的輸入框裡執行.

    $claude

    開啟新的 Claude Code session. Plugin 在 session 開始時啟動 relay. 安裝 plugin 之前就開啟的 session 不會載入 plugin.

    >/relay status

    顯示這個 session 的路由, relay, proxy 和 Codex 用量. 確認 Relay: 這一行有 pid 和版本號碼.

    這個視窗: Claude (尚未送出 request, 將使用預設) 新 session 預設: Claude Relay: http://127.0.0.1:8960 (pid ..., 0.1.0, 固定的 session: 0) Codex proxy: 未執行 127.0.0.1:8970 (claude-code-proxy)

    Proxy 在第一次切到 Codex 時才會啟動. 所以這時 proxy 顯示 未執行 是正常的.

    >/relay codex

    把這個視窗切換到 Codex. Relay 會在這時啟動 proxy. 其他視窗不受影響.

    >/relay status

    再檢查一次. 這次 proxy 應該顯示 執行中.

    >/relay models

    列出你的帳號可以使用的 Codex model, 以及 proxy 是否支援每個 model.

    送出一則訊息. Statusline 顯示類似 ⇄ Codex gpt-5.6-terra · ctx 42% · 5h 23% · 週 41% 時, 安裝就完成了.

    >/relay claude

    把這個視窗切回 Claude.

    08

    常用指令

    下面的指令都在 Claude Code 輸入框裡執行.

    >/relay

    開啟面板. 按 ctrl+x tab 聚焦面板, 再按按鈕上標示的鍵.

    >/relay default codex

    讓新的 session 預設走 Codex. 已經開始的對話不會換路徑, 也不會重建 prompt cache. 改回來請用 /relay default claude.

    >/relay usage

    顯示 Codex 方案的用量上限 (5 小時與每週).

    >/relay models --full

    列出所有 Codex model, 包含帳號隱藏的 model.

    >/relay auth status

    顯示 Codex 的登入狀態.

    >/relay auth login

    開啟瀏覽器重新登入. 無法開啟瀏覽器時 (例如透過 SSH), 改用 /relay auth device.

    >/relay monitor

    顯示開啟 monitor TUI 的指令. Monitor 是全螢幕畫面, 請在另一個終端機執行它.

    $claude-code-proxy monitor --url http://127.0.0.1:8970

    在另一個終端機執行. 連到執行中的 proxy, 即時顯示 request 和用量. 這是唯讀畫面. 有修改 proxyPort 時, 請換成你的 port.

    Subagent

    主對話可以留在 Claude. 使用 codex-relay:codex agent type 的 subagent 會在 Codex 上執行, model 由設定中的 agentModel 指定.

    09

    設定 (選用)

    預設值通常就能使用. 需要修改時, 編輯 ~/.claude/codex-relay.json. 有設定 CLAUDE_CONFIG_DIR 時, 檔案放在該目錄. 檔案不存在時使用預設值.

    欄位預設值說明
    port8960Relay 的 port
    proxyPort8970Proxy 的 port
    proxyCommand"claude-code-proxy"Proxy 的執行檔名稱或完整路徑
    defaultRoute"claude"新 session 的路由: "claude" 或 "codex"
    agentModel"gpt-5.6-terra"codex-relay:codex subagent 使用的 model
    claudeUrl"https://api.anthropic.com"Claude 路由的上游位址
    nodePath"node"啟動 relay 使用的 Node 執行檔

    修改設定後, 在 Claude Code 執行 /relay restart 讓 relay 讀取新設定. 修改 proxyPort 或 proxyCommand 時, 改用 /relay restart --proxy.

    10

    疑難排解

    Relay 或 proxy 沒有回應

    >/relay restart --proxy

    停止 relay 和 proxy, 然後重新啟動 relay. Proxy 會在下一次需要 Codex 時啟動.

    查看 relay 的 log

    PS>Get-Content "$env:USERPROFILE\.claude\codex-relay.log" -Tail 50

    顯示 relay log 的最後 50 行. Log 超過 5 MB 時會被清空.

    $tail -n 50 ~/.claude/codex-relay.log

    顯示 relay log 的最後 50 行. Log 超過 5 MB 時會被清空.

    查看 proxy 的 log

    PS>Get-Content "$env:LOCALAPPDATA\claude-code-proxy\proxy.log" -Tail 50

    顯示 proxy log 的最後 50 行. Codex 回傳錯誤時, 原因通常記在這裡.

    $tail -n 50 ~/.local/state/claude-code-proxy/proxy.log

    顯示 proxy log 的最後 50 行. 有設定 XDG_STATE_HOME 時, log 在該目錄下的 claude-code-proxy/.

    /relay status 顯示 proxy 錯誤, 或找不到 claude-code-proxy

    PS>(Get-Command claude-code-proxy).Source

    顯示 proxy 執行檔的完整路徑. 沒有輸出代表它不在 PATH 裡.

    $command -v claude-code-proxy

    顯示 proxy 執行檔的完整路徑. 沒有輸出代表它不在 PATH 裡.

    找不到時, 請重新開啟終端機和 Claude Code. 還是找不到時, 把 proxyCommand 設為執行檔的完整路徑 (見步驟 09).

    已經使用 model-relay

    兩者都會設定 ANTHROPIC_BASE_URL. 啟用這個 plugin 後, session 改走 codex-relay. 要讓 Claude 路由繼續經過 model-relay, 把 claudeUrl 設為 model-relay 的位址.

    11

    更新與移除

    更新 proxy

    在步驟 05 下載的 codex-relay 資料夾中執行.

    $git pull

    下載最新的原始碼.

    $cargo install --path proxy --force

    重新編譯並覆蓋已安裝的 proxy. --force 讓 cargo 在版本號碼相同時也重新安裝.

    更新 plugin

    $claude plugin marketplace update codex-relay

    從 GitHub 讀取 marketplace 的最新內容.

    $claude plugin update codex-relay@codex-relay

    把 plugin 更新到最新版本. 更新後請重新開啟 Claude Code. 新 session 會自動重新啟動舊版的 relay.

    移除

    >/relay stop --proxy

    在 Claude Code 中執行. 停止 relay 和 proxy, 讓後面的移除步驟不會被執行中的程式擋住.

    $claude plugin uninstall codex-relay@codex-relay

    移除 plugin.

    $claude plugin marketplace remove codex-relay

    從 marketplace 清單移除 codex-relay.

    $cargo uninstall claude-code-proxy

    刪除 cargo 安裝的 proxy 執行檔.

    設定檔 ~/.claude/codex-relay.json, 路由狀態 ~/.claude/codex-relay-state.json 和 log 不會自動刪除. 不再需要時, 請手動刪除.
