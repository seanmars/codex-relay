codex-relay 安裝指南
你的作業系統:
完成 0 / 0

    用安裝腳本安裝 codex-relay

    codex-relay 讓每個 Claude Code 視窗各自選擇走 Claude 或 OpenAI Codex. 安裝分成兩部分: Rust 寫的 claude-code-proxy, 以及 Claude Code plugin.

    安裝腳本會完成所有安裝工作: Windows 使用 scripts/install.ps1, macOS 和 Linux 使用 scripts/install.sh. 安裝後, 依照後面的步驟驗證和使用. 請先在右上角選擇你的作業系統.

    Claude Code ── ANTHROPIC_BASE_URL ──▶ relay (Node, 127.0.0.1:8960)
                                        ├─ session = claude ─▶ api.anthropic.com
                                        └─ session = codex  ─▶ claude-code-proxy (Rust, 127.0.0.1:8970)
                                                                 └─▶ chatgpt.com/backend-api/codex
    01

    執行安裝腳本

    腳本會檢查每個工具, 只安裝缺少的部分. 每個指令執行前, 腳本會顯示指令和原因, 並詢問 [Y/n]. 按 Ctrl+C 可以隨時停止.

    腳本會處理的項目

    項目腳本的動作
    Node.js 缺少時, 用 winget 安裝. 缺少時, 用 Homebrew 安裝. 缺少時, 顯示 nodejs.org 的下載位址. 發行版內建的版本常常太舊, 所以腳本不自動安裝. Node.js 需要 v20 以上.
    Git 缺少時, 用 winget 安裝. 缺少 Apple Command Line Tools 時, 執行 xcode-select --install. Command Line Tools 內含 git 和 C linker. 缺少時, 用 apt-get, dnf, pacman 或 zypper 安裝. 腳本也會安裝缺少的 curl.
    Claude Code缺少時, 執行官方安裝程式. 已經安裝時, 詢問是否執行 claude update.
    Rust toolchain 缺少時, 下載並執行 rustup-init.exe. 缺少時, 執行 rustup 的官方安裝腳本. 缺少 C compiler 時, 用套件管理工具安裝.
    Codex CLI缺少時, 用 npm 安裝. 尚未登入時, 執行 codex login.
    claude-code-proxy下載原始碼, 用 cargo install 編譯並安裝. 已經安裝時, 詢問是否重新編譯.
    Claude Code plugin加入 marketplace, 安裝並啟用 codex-relay plugin.

    你需要一個有 Codex 使用權的 ChatGPT 帳號. 腳本執行 codex login 時, 會開啟瀏覽器讓你登入.

    執行腳本

    腳本需要 PowerShell 7. 請在 PowerShell 或 Windows Terminal 中逐行執行.

    PS>winget install --id Microsoft.PowerShell --exact --source winget

    安裝 PowerShell 7. 已經有 pwsh 時, 請略過這行.

    PS>pwsh

    在目前的視窗開啟 PowerShell 7. 剛安裝完 PowerShell 7 時, 請先開啟新的終端機再執行這行.

    PS>irm https://raw.githubusercontent.com/seanmars/codex-relay/main/scripts/install.ps1 | iex

    下載並執行安裝腳本. 腳本詢問原始碼的資料夾時, 按 Enter 使用目前目錄下的 codex-relay, 或輸入其他路徑.

    已經下載原始碼時, 可以在原始碼資料夾執行 pwsh -ExecutionPolicy Bypass -File scripts\install.ps1. 腳本會直接使用這份原始碼.

    腳本需要 bash. macOS 內建的 bash 3.2 可以使用. 請在終端機中執行.

    $curl -fsSL https://raw.githubusercontent.com/seanmars/codex-relay/main/scripts/install.sh | bash

    下載並執行安裝腳本. 請用 bash, 不要用 sh. 腳本詢問原始碼的資料夾時, 按 Enter 使用目前目錄下的 codex-relay, 或輸入其他路徑.

    已經下載原始碼時, 可以在原始碼資料夾執行 bash scripts/install.sh. 腳本會直接使用這份原始碼.

    安裝 Git, curl 或 C compiler 時, 腳本使用 sudo. 系統會詢問你的密碼.

    某一步失敗時, 修正問題後重新執行腳本. 已經完成的步驟會自動略過. 有工具還是顯示 [缺少] 時, 請重新開啟終端機, 再執行一次.

    腳本顯示 == 完成 == 後, 開啟新的終端機, 讓 PATH 生效. 然後從 步驟 02 繼續.

    02

    開啟 Claude Code 並驗證

    下面第一行在終端機執行. 其他以 / 開頭的指令, 請在 Claude Code 的輸入框裡執行.

    $claude

    開啟新的 Claude Code session. Plugin 在 session 開始時啟動 relay. 安裝 plugin 之前就開啟的 session 不會載入 plugin.

    >/relay status

    顯示這個 session 的路由, relay, proxy 和 Codex 用量. 確認 Relay: 這一行有 pid 和版本號碼.

    這個視窗: Claude (尚未送出 request, 將使用預設) 新 session 預設: Claude Relay: http://127.0.0.1:8960 (pid ..., 0.1.0, 固定的 session: 0) Codex proxy: 未執行 127.0.0.1:8970 (claude-code-proxy)

    Proxy 在第一次切到 Codex 時才會啟動. 所以這時 proxy 顯示 未執行 是正常的.

    >/relay codex

    把這個視窗切換到 Codex. Relay 會在這時啟動 proxy. 其他視窗不受影響.

    >/relay status

    再檢查一次. 這次 proxy 應該顯示 執行中.

    >/relay models

    列出你的帳號可以使用的 Codex model, 以及 proxy 是否支援每個 model.

    送出一則訊息. Statusline 顯示類似 ⇄ Codex gpt-5.6-terra · ctx 42% · 5h 23% · 週 41% 時, 安裝就完成了.

    >/relay claude

    把這個視窗切回 Claude.

    03

    常用指令

    下面的指令都在 Claude Code 輸入框裡執行.

    >/relay

    開啟面板. 按 ctrl+x tab 聚焦面板, 再按按鈕上標示的鍵.

    >/relay default codex

    讓新的 session 預設走 Codex. 已經開始的對話不會換路徑, 也不會重建 prompt cache. 改回來請用 /relay default claude.

    >/relay usage

    顯示 Codex 方案的用量上限 (5 小時與每週).

    >/relay models --full

    列出所有 Codex model, 包含帳號隱藏的 model.

    >/relay auth status

    顯示 Codex 的登入狀態.

    >/relay auth login

    開啟瀏覽器重新登入. 無法開啟瀏覽器時 (例如透過 SSH), 改用 /relay auth device.

    >/relay monitor

    顯示開啟 monitor TUI 的指令. Monitor 是全螢幕畫面, 請在另一個終端機執行它.

    $claude-code-proxy monitor --url http://127.0.0.1:8970

    在另一個終端機執行. 連到執行中的 proxy, 即時顯示 request 和用量. 這是唯讀畫面. 有修改 proxyPort 時, 請換成你的 port.

    Subagent

    主對話可以留在 Claude. 使用 codex-relay:codex agent type 的 subagent 會在 Codex 上執行, model 由設定中的 agentModel 指定.

    04

    設定 (選用)

    預設值通常就能使用. 需要修改時, 編輯 ~/.claude/codex-relay.json. 有設定 CLAUDE_CONFIG_DIR 時, 檔案放在該目錄. 檔案不存在時使用預設值.

    欄位預設值說明
    port8960Relay 的 port
    proxyPort8970Proxy 的 port
    proxyCommand"claude-code-proxy"Proxy 的執行檔名稱或完整路徑
    defaultRoute"claude"新 session 的路由: "claude" 或 "codex"
    agentModel"gpt-5.6-terra"codex-relay:codex subagent 使用的 model
    claudeUrl"https://api.anthropic.com"Claude 路由的上游位址
    nodePath"node"啟動 relay 使用的 Node 執行檔

    修改設定後, 在 Claude Code 執行 /relay restart 讓 relay 讀取新設定. 修改 proxyPort 或 proxyCommand 時, 改用 /relay restart --proxy.

    05

    疑難排解

    Relay 或 proxy 沒有回應

    >/relay restart --proxy

    停止 relay 和 proxy, 然後重新啟動 relay. Proxy 會在下一次需要 Codex 時啟動.

    查看 relay 的 log

    PS>Get-Content "$env:USERPROFILE\.claude\codex-relay.log" -Tail 50

    顯示 relay log 的最後 50 行. Log 超過 5 MB 時會被清空.

    $tail -n 50 ~/.claude/codex-relay.log

    顯示 relay log 的最後 50 行. Log 超過 5 MB 時會被清空.

    查看 proxy 的 log

    PS>Get-Content "$env:LOCALAPPDATA\claude-code-proxy\proxy.log" -Tail 50

    顯示 proxy log 的最後 50 行. Codex 回傳錯誤時, 原因通常記在這裡.

    $tail -n 50 ~/.local/state/claude-code-proxy/proxy.log

    顯示 proxy log 的最後 50 行. 有設定 XDG_STATE_HOME 時, log 在該目錄下的 claude-code-proxy/.

    /relay status 顯示 proxy 錯誤, 或找不到 claude-code-proxy

    PS>(Get-Command claude-code-proxy).Source

    顯示 proxy 執行檔的完整路徑. 沒有輸出代表它不在 PATH 裡.

    $command -v claude-code-proxy

    顯示 proxy 執行檔的完整路徑. 沒有輸出代表它不在 PATH 裡.

    找不到時, 請重新開啟終端機和 Claude Code. 還是找不到時, 把 proxyCommand 設為執行檔的完整路徑 (見步驟 04).

    已經使用 model-relay

    兩者都會設定 ANTHROPIC_BASE_URL. 啟用這個 plugin 後, session 改走 codex-relay. 要讓 Claude 路由繼續經過 model-relay, 把 claudeUrl 設為 model-relay 的位址.

    06

    更新與移除

    更新 proxy

    在安裝時下載的 codex-relay 資料夾中執行.

    $git pull

    下載最新的原始碼.

    PS>pwsh -ExecutionPolicy Bypass -File scripts\install.ps1

    用這份原始碼重新執行安裝腳本. 腳本詢問是否重新編譯 proxy 時, 回答 y. 腳本會先停止執行中的 proxy, 再覆蓋執行檔. 編譯期間請不要使用 Codex session.

    $bash scripts/install.sh

    用這份原始碼重新執行安裝腳本. 腳本詢問是否重新編譯 proxy 時, 回答 y.

    >/relay restart --proxy

    在 Claude Code 中執行. 執行中的 proxy 還是舊版, 這行讓 relay 改用新版. Proxy 沒有執行時, 不需要這行.

    更新 plugin

    $claude plugin marketplace update codex-relay

    從 GitHub 讀取 marketplace 的最新內容.

    $claude plugin update codex-relay@codex-relay

    把 plugin 更新到最新版本. 更新後請重新開啟 Claude Code. 新 session 會自動重新啟動舊版的 relay.

    移除

    $node relay/cli.mjs stop --proxy

    在安裝時下載的 codex-relay 資料夾中執行. 停止 relay 和 proxy, 讓後面的移除步驟不會被執行中的程式擋住.

    $claude plugin uninstall codex-relay@codex-relay

    移除 plugin.

    $claude plugin marketplace remove codex-relay

    從 marketplace 清單移除 codex-relay.

    $cargo uninstall claude-code-proxy

    刪除 cargo 安裝的 proxy 執行檔.

    設定檔 ~/.claude/codex-relay.json, 路由狀態 ~/.claude/codex-relay-state.json 和 log 不會自動刪除. 不再需要時, 請手動刪除.
